# AGENTS.md

## Mandatory clarification rule

Before making changes in this repository, ask the user clarifying questions and
wait for an answer.

This applies before editing files, adding/removing public API, changing routes,
changing tests, updating docs, creating commits/tags, installing dependencies,
or running commands that do more than read local state.

Read-only inspection is allowed only to understand the current project state and
to ask better questions. Do not infer product decisions, add compatibility
endpoints, or create behavior the user did not explicitly request.

Skip the clarification step only when the user explicitly says to proceed
without questions, for example: "делай без вопросов", "исправь сам", or
"можно не уточнять".
